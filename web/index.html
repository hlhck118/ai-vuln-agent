    MCP 服务 外部工具接入 · stdio 或 HTTP 尚未加载

    这里的服务由外部程序实现，工具跑在控制面这台 机器上。它们不产出目标证据（结果不进探索链路、漏洞或报告）， 返回值按不可信输入处理。每条服务声明一个权限档：档位越高，能拿到它的会话越少 （full 最窄，只有完全作业档的会话能拿到）。

    添加 MCP 服务
    档位越高，能拿到它的会话越少（full 最窄）
    每行一个

    批准与 chat_review 档位一起生效。外部工具与 run_command 同类：在这台机器上由外部代码执行、不受适配器表约束， 所以「要人先看一眼」是默认，而不是去猜这个工具危不危险。

    每行一条 KEY=VALUE；stdio 服务用它设编码等

    保存之后会立刻连一次：连不上的原因（命令找不到、服务报错、 超时）会显示在那张卡片上。探测失败不影响保存——配置已经落库， 改好再点「测试连接」即可。stdio 服务的输出必须是 UTF-8（MCP 的规定）； 卡片上出现编码提醒时，加一条 PYTHONIOENCODING=utf-8 即可。

    工具拦截 按入参正则拦下不可逆操作 尚未加载
